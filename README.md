## 📋 Sobre o Projeto

**TaskFlow** é uma aplicação web moderna para gerenciamento de tarefas e projetos, projetada para aumentar a produtividade individual através de uma interface intuitiva e recursos avançados de organização.

O sistema permite criar, organizar e acompanhar tarefas — vinculadas a projetos ou de forma independente — com suporte a tags personalizadas, prazos, filtros inteligentes e análise de produtividade em tempo real.

### 🎯 Problema Resolvido

Muitas ferramentas de gerenciamento são complexas demais ou simples demais. O TaskFlow encontra o equilíbrio perfeito entre funcionalidade e usabilidade, oferecendo recursos avançados sem sobrecarregar o usuário.

## ✨ Funcionalidades

### Tarefas

- ✅ **CRUD Completo** — Criar, visualizar, editar e excluir tarefas
- 📁 **Vinculação a Projetos** — Associe tarefas a um projeto ou deixe-as independentes
- 🎨 **Priorização Visual** — Classifique por prioridade (Alta, Média, Baixa)
- ⭐ **Favoritos** — Marque tarefas importantes para acesso rápido
- 📅 **Gerenciamento de Prazos** — Defina e acompanhe datas de vencimento

### Projetos

- 📁 **CRUD Completo** — Criar, visualizar, editar e excluir projetos
- 📊 **Progresso Automático** — Acompanhe o avanço com base nas tarefas concluídas
- 🔖 **Status Dinâmico** — Ativo, Concluído, Pausado ou Cancelado
- 🗂️ **Visão Detalhada** — Acesse todas as tarefas de um projeto em um só lugar

### Tags

- 🏷️ **CRUD Completo** — Crie, edite e remova tags com cores personalizadas
- 🔗 **Uso Cruzado** — Aplique tags em tarefas e projetos
- 📈 **Contador de Uso** — Veja quantas tarefas e projetos cada tag possui
- 🛡️ **Remoção Segura** — Alerta ao excluir tags vinculadas a itens existentes

### Recursos Gerais

- 🔍 **Busca Global** — Encontre tarefas e projetos simultaneamente em tempo real
- 🔄 **Filtros e Ordenação** — Filtre por status, prioridade, tags, prazos e muito mais
- 📊 **Dashboard Analítico** — Visualize estatísticas de tarefas e projetos
- 💾 **Persistência Local** — Dados salvos automaticamente no navegador
- 📱 **Design Responsivo** — Interface adaptada para desktop, tablet e mobile
- 🌙 **Tema Escuro** — Alterne entre modo claro e escuro

## 🚀 Como Executar o Projeto

### Pré-requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Não requer instalação de dependências!

### Instalação

1. **Clone o repositório**

```bash
git clone https://github.com/joseantoniojr/taskflow.git
```

2. **Navegue até a pasta do projeto**

```bash
cd taskflow
```

3. **Abra o arquivo `index.html` no navegador**
    - Clique duas vezes no arquivo, ou
    - Arraste para o navegador, ou
    - Use a extensão Live Server no VS Code

4. **Pronto!** A aplicação estará rodando localmente.
